# BBK7980 SDK 1.1.1 社区预发布

新增 PNG 图标支持及独立转换工具：

- `project.json` 可直接设置 `"icon": "icon.png"`，构建时自动转为原机点阵格式。
- `python tools/convert_icon.py icon.png -o icon.bin --preview icon-preview.png` 可单独生成点阵和预览。
- 保持宽高比适配 32×24 可见区域，透明部分铺白底，转为四级灰度，底部隐藏区域填零。
- PNG 和预览需安装 `python -m pip install -r requirements-images.txt`；原始 `.bin` 和默认图标仍只需 Python 标准库。
- README 补全 11 个原厂分类、图标格式、可见区域与使用命令。

CI 从源码构建，运行 13 项宿主 C 测试和 10 项图标测试，并检查 PNG 图标及分类实际写入应用传输文件。
五个既有设备示例与 1.1.0 的模拟器验证二进制逐字节相同；原来的 30 项基础和 19 项 I/O 来宾证据继续适用。
PNG 图标另在原厂固件模拟器中确认桌面可见像素、UART 读回、非默认分类启动及按键退出。

下载 `BBK7980-SDK-1.1.1-win64.zip`，解压后使用 Python 3.10+ 构建。
`SHA256SUMS.txt` 和 `build-report.json` 随附；五个预编译应用位于 `bin/`。

**真机与 PCLINK 仍待实测。** SDK 适配 7980 V1.10，不含原厂固件、NAND、字库或 PCLINK。
核心 MIT，扫雷与可选模拟器 GPLv3；PNG 依赖 Pillow 单独保留其许可，不随 SDK 捆绑。
