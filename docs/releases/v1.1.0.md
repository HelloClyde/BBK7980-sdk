# BBK7980 SDK 1.1.0 社区预发布

面向朗文 7980 V1.10 的 C/65C02 SDK 首次公开源码发行。

- 原厂事件/键码、周期事件、原机字模服务、四灰阶绘图。
- 文件查找、读写、创建、更新、定位、关闭、删除。
- 系统中断持续服务的 PSG 音符序列。
- 五个示例、项目模板、API/ABI/安装文档和实际模拟器截图。
- 固定 cc65 完整源码提交及 SHA-256，Windows 构建工具链随 ZIP 提供。
- SDK 核心 MIT；扫雷和可选模拟器 GPLv3，各部分独立保留许可。

下载 `BBK7980-SDK-1.1.0-win64.zip`；解压后安装 Python 3.10+，运行
`python -X utf8 tools/build.py examples/hello`。五个预编译应用在 `bin/`。
给设备传输的是 BJBBK.110 应用文件，具体步骤见包内 `docs/INSTALL.md`。

CI 从源码构建并验证五个传输文件、13 项宿主 C 测试及外部项目模板；
发布的设备二进制必须与已有原厂固件模拟器验证的哈希完全一致。
既有模拟器记录包含 30 项基础检查与 19 项文件/音乐检查，未在公共 CI 中重新执行。
`SHA256SUMS.txt` 和 `build-report.json` 随附，上传前后均校验归档及内部文件清单。

**真机和 PCLINK 尚待实测，因此标为预发布。** 限定 V1.10 固件；
没有原厂 ROM、NAND、字库或 PCLINK。截图中的字形取自测试环境的兼容字体输入，
不宣称恢复了原机字库。音乐接口为 PSG 音符序列，未实现通用 WAV/MP3 解码。
